Download complete project (VS Code)

Zip size about 35 MB. Includes source, trained SOC model, datasets, and VS Code tasks.

Download CarbonCreditFarm-complete.zip

Then on your PC

  1. Install VS Code, Node.js LTS, and Python 3.10+
  2. Unzip the file
  3. VS Code → File → Open Folder → CarbonCreditFarm
  4. Terminal → Run Task → Install all
  5. Terminal → Run Task → Start CarbonCreditFarm
  6. Open http://127.0.0.1:43123

Windows: after unzip, double-click scripts/start-windows.bat
